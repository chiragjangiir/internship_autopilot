Questions people ask first

Short answers here, details in the README.

Does it send anything on its own?

No. Every email and every reply waits for you to type “send”.

Is this a mass mailing tool?

No. It is built for a few personal emails a day, each one written for one person.

Where do the email addresses come from?

Only from public pages, with the source link saved. Addresses are never guessed.

Can it make my CV sound better than it is?

No. The claims checker removes anything that is not in your facts file.

Do I need both a Mac and a PC?

No. Use either sender. The Windows route is only for running batches unattended.

How do I stop a run right now?

Create a file called STOP next to the script. Sending halts before the next email.
