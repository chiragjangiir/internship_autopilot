Setup: pick one sender, or use both

The assistant prepares the same drafts either way. Only the last mile differs.

Mac · Apple Mail

Interactive sending, replies in thread, calendar entries
  1. Copy scripts/mac to your Mac and make the scripts executable
  2. Add your sending account to Apple Mail
  3. Allow Terminal to control Mail and Calendar (asked on first run)
  4. Put your facts file and current CV in data/
  5. Send one test email to yourself with send_att.sh

Windows PC · Outlook

Unattended batches on a spare PC, every day
  1. Install classic Outlook and sign in to your sending account
  2. Copy scripts/windows to C:\autopilot
  3. Run a dry run first: send_drafts.ps1 only_list.txt 100 DryRun
  4. Register the daily task with install_task.ps1
  5. Optional: reach the PC over SSH through a private VPN such as Tailscale
